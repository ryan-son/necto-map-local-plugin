# Mocked Cookie Journal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Map Local journals every cookie its mocks write to `HTTPCookieStorage.shared`, sets them aside when it is turned off, puts them back when it is turned on, and discards them exactly on request, through the CLI, the panel and a Swift API.

**Architecture:** A `CookieKeeper` in `MapLocalCore` owns the journal, a lock and an injected `CookieJar`. The engine owns one keeper, routes the URL protocol's cookie writes through it, calls it when `enabled` flips and at launch, and publishes its counts in `EngineState`. Two new operations (`maplocal.cookies.restore`, `maplocal.cookies.list`) expose it to `necto-cli` and the panel.

**Tech Stack:** Swift 6 (Swift Testing, `OSAllocatedUnfairLock`, `os.Logger`), Foundation `HTTPCookieStorage`, TypeScript panel (vitest, jsdom), Necto manifest.

**Spec:** `docs/superpowers/specs/2026-10-12-mocked-cookie-journal-design.md`. Read it before any task; this plan argues from it.

## Review Focus

1. A mocked logout (`Set-Cookie: sid=; Max-Age=0`) over a real cookie, then a discard: the real cookie must come back (Task 4, test `discardRestoresAfterMockedDeletion`).
2. A real login while Map Local is off, then turning it on: the real cookie must win over the set-aside mock (Task 5, test `putBackDropsWhenRealChangedWhileOff`).
3. The same rule answering two different URL paths with a `Set-Cookie` that has no `Path=`: two keys, both discarded (Task 3, test `writeWithoutPathMakesOneKeyPerPath`).
4. A cookie re-enabled by "on" must not be undone at the next launch by the pending check (Task 5, test `pendingCheckSkipsKeysPutBack`).
5. A disk-full journal save during a discard: the call fails with the counts, and the in-memory journal still matches the file (Task 4, test `discardKeepsJournalWhenSaveFails`).

```swift
#if MAP_LOCAL_ENABLED
import Foundation

/// The identity `HTTPCookieStorage` replaces a cookie by.
///
/// A host-only cookie keeps the bare host as its domain and a `Domain=` cookie gets a
/// leading dot, so the two are different keys, as they are in the storage.
public struct CookieKey: Hashable, Codable, Sendable {
    public var domain: String
    public var path: String
    public var name: String

    public init(domain: String, path: String, name: String) {
        self.domain = domain
        self.path = path
        self.name = name
    }

    public init(_ cookie: HTTPCookie) {
        self.init(domain: cookie.domain, path: cookie.path, name: cookie.name)
    }
}

/// A cookie as the journal keeps it.
///
/// `HTTPCookie.properties` holds dates, numbers and arrays that `JSONSerialization`
/// rejects, so the journal stores these fields instead. `Created` is left out: it changes
/// on every write and says nothing about the cookie.
public struct CookieRecord: Codable, Equatable, Sendable {
    public var name: String
    public var value: String
    public var domain: String
    public var path: String
    /// Whole seconds since 1970, or nil for a session cookie. Storage keeps whole seconds,
    /// so comparing at this precision matches what is read back.
    public var expires: Int?
    public var secure: Bool
    public var httpOnly: Bool
    public var sameSite: String?
    public var comment: String?
    public var commentURL: String?
    public var ports: [Int]
    public var version: Int

    public init(_ cookie: HTTPCookie) {
        name = cookie.name
        value = cookie.value
        domain = cookie.domain
        path = cookie.path
        expires = cookie.expiresDate.map { Int($0.timeIntervalSince1970.rounded(.down)) }
        secure = cookie.isSecure
        httpOnly = cookie.isHTTPOnly
        sameSite = cookie.sameSitePolicy?.rawValue
        comment = cookie.comment
        commentURL = cookie.commentURL?.absoluteString
        ports = (cookie.portList ?? []).map(\.intValue)
        version = cookie.version
    }

    public var key: CookieKey { CookieKey(domain: domain, path: path, name: name) }

    public var isSession: Bool { expires == nil }

    public func hasExpired(at now: Date) -> Bool {
        expires.map { TimeInterval($0) <= now.timeIntervalSince1970 } ?? false
    }

    /// The cookie to store again, or nil if Foundation refuses the fields.
    public var cookie: HTTPCookie? {
        var properties: [HTTPCookiePropertyKey: Any] = [
            .name: name,
            .value: value,
            .domain: domain,
            .path: path,
            .version: String(version),
        ]
        if let expires { properties[.expires] = Date(timeIntervalSince1970: TimeInterval(expires)) }
        if secure { properties[.secure] = "TRUE" }
        if httpOnly { properties[HTTPCookiePropertyKey("HttpOnly")] = "TRUE" }
        if let sameSite { properties[.sameSitePolicy] = sameSite }
        if let comment { properties[.comment] = comment }
        if let commentURL { properties[.commentURL] = commentURL }
        if !ports.isEmpty { properties[.port] = ports.map(String.init).joined(separator: ",") }
        return HTTPCookie(properties: properties)
    }
}
#endif
```

```swift
#if MAP_LOCAL_ENABLED
import Foundation

/// The cookie storage Map Local writes mocked cookies to and restores from.
///
/// The app's engine uses `HTTPCookieStorage.shared`; tests use an isolated storage, so no
/// test touches the shared one.
public protocol CookieJar: Sendable {
    /// The cookie stored under `key`, if any.
    func cookie(_ key: CookieKey) -> HTTPCookie?
    /// Stores a response's cookies as the loading system would, applying the accept policy.
    func setCookies(_ cookies: [HTTPCookie], for url: URL, mainDocumentURL: URL?)
    /// Stores one cookie whatever the accept policy, so a strict policy cannot block a restore.
    func set(_ cookie: HTTPCookie)
    func delete(_ key: CookieKey)
}

/// A `CookieJar` over an `HTTPCookieStorage`.
public struct StorageCookieJar: CookieJar, @unchecked Sendable {
    // `HTTPCookieStorage` is thread-safe but not marked `Sendable`.
    private let storage: HTTPCookieStorage

    public init(_ storage: HTTPCookieStorage = .shared) { self.storage = storage }

    /// A storage of its own, for tests.
    static func isolated(policy: HTTPCookie.AcceptPolicy = .always) -> StorageCookieJar {
        let storage = HTTPCookieStorage.sharedCookieStorage(forGroupContainerIdentifier: "maplocal.test.\(UUID().uuidString)")
        storage.cookieAcceptPolicy = policy
        return StorageCookieJar(storage)
    }

    public func cookie(_ key: CookieKey) -> HTTPCookie? {
        (storage.cookies ?? []).first { CookieKey($0) == key }
    }

    public func setCookies(_ cookies: [HTTPCookie], for url: URL, mainDocumentURL: URL?) {
        storage.setCookies(cookies, for: url, mainDocumentURL: mainDocumentURL)
    }

    public func set(_ cookie: HTTPCookie) { storage.setCookie(cookie) }

    public func delete(_ key: CookieKey) {
        if let cookie = cookie(key) { storage.deleteCookie(cookie) }
    }
}
#endif
```

```swift
#if MAP_LOCAL_ENABLED
import Foundation

/// What a mocked write left under a key, read back from storage after the write.
public enum CookieWrite: Codable, Equatable, Sendable {
    case stored(CookieRecord)
    /// The mock removed the cookie, with a `Max-Age=0` or a past `Expires`.
    case deleted

    /// Whether `stored`, the cookie now under the key, is still what the mock left.
    public func matches(_ stored: CookieRecord?) -> Bool {
        switch self {
        case let .stored(record): stored == record
        case .deleted: stored == nil
        }
    }
}

/// One key a mock has written, and the real value to bring back.
public struct CookieEntry: Codable, Equatable, Sendable {
    public enum Layer: String, Codable, Sendable {
        /// The mock's cookie is in storage.
        case active
        /// Map Local is off and the real value is back; turning it on puts the mock's back.
        case setAside
    }

    public var key: CookieKey
    /// The real cookie before the mock took the key, or nil when there was none.
    public var before: CookieRecord?
    /// The launch `before` was read in. A session `before` from an earlier launch has died.
    public var beforeLaunchID: String
    public var written: CookieWrite
    /// The launch of the last mocked write.
    public var launchID: String
    public var layer: Layer = .active
    /// For a set-aside entry, what storage held right after it was set aside.
    public var restoredTo: CookieRecord?
}

/// Every key Map Local's mocks have written, kept in the app's container.
public struct CookieJournal: Codable, Equatable, Sendable {
    public var entries: [CookieEntry] = []
    /// Restored entries the next launch checks again, in case a kill lost the restore
    /// before `HTTPCookieStorage` saved it.
    public var pending: [CookieEntry] = []

    public static let empty = CookieJournal()
}

/// A journal as it was loaded.
public enum CookieJournalLoad: Equatable, Sendable {
    case loaded(CookieJournal)
    /// The file exists but cannot be read, such as before first unlock. It is never
    /// overwritten.
    case unreadable(String)
    /// The file was not a journal and was deleted. It held real cookies, so it is not kept.
    case invalid
}
#endif
```

```swift
import Foundation
```

```swift
/// A journaled key, as `maplocal.cookies.list` reports it. Never carries a value.
public struct CookieListing: Equatable, Sendable {
    public var key: CookieKey
    public var layer: CookieEntry.Layer
    public var isCurrentLaunch: Bool
}

/// Writes mocked cookies, journals them, and brings real ones back.
///
/// One lock covers reading a key, writing it, journaling it and restoring it, so a
/// restore can never fall between a write's read and its store. It is never held together
/// with the engine's state lock.
final class CookieKeeper: Sendable {
    private struct Inner {
        var journal: CookieJournal
        /// The file could not be read, so it is never written and nothing is restored.
        var readOnly: Bool
    }

    private let lock: OSAllocatedUnfairLock<Inner>
    let jar: any CookieJar
    let store: ConfigurationStore
    let launchID: String
    let now: @Sendable () -> Date
    let issues: [MapLocalMessage]
    static let logger = Logger(subsystem: "io.github.ryan-son.maplocal", category: "cookies")

    init(store: ConfigurationStore, jar: any CookieJar, launchID: String, now: @escaping @Sendable () -> Date) {
        self.store = store
        self.jar = jar
        self.launchID = launchID
        self.now = now
        switch store.loadCookieJournal() {
        case let .loaded(journal):
            lock = OSAllocatedUnfairLock(initialState: Inner(journal: journal, readOnly: false))
            issues = []
        case let .unreadable(error):
            lock = OSAllocatedUnfairLock(initialState: Inner(journal: .empty, readOnly: true))
            issues = [MapLocalMessage(.cookieJournalUnreadable, ["error": error])]
        case .invalid:
            lock = OSAllocatedUnfairLock(initialState: Inner(journal: .empty, readOnly: false))
            issues = [MapLocalMessage(.cookieJournalDeleted)]
            Self.logger.error("The cookie journal was not valid and was deleted")
        }
    }

    var journal: CookieJournal { lock.withLock { $0.journal } }

    var counts: (active: Int, setAside: Int) {
        lock.withLock { inner in
            let active = inner.journal.entries.filter { $0.layer == .active }.count
            return (active, inner.journal.entries.count - active)
        }
    }

    func listing() -> [CookieListing] {
        lock.withLock { inner in
            inner.journal.entries.map {
                CookieListing(key: $0.key, layer: $0.layer, isCurrentLaunch: $0.launchID == launchID)
            }
        }
    }

    func stored(_ key: CookieKey) -> CookieRecord? { jar.cookie(key).map(CookieRecord.init) }

    /// Writes a mocked response's cookies and journals what storage holds afterwards.
    ///
    /// The entry is saved before the write, so a crash leaves an entry and never an
    /// untracked mocked cookie. A failed save is logged and the journal stays in memory.
    func write(_ cookies: [HTTPCookie], for url: URL, mainDocumentURL: URL?) {
        lock.withLock { inner in
            for cookie in cookies {
                let key = CookieKey(cookie)
                let before = stored(key)
                let index = inner.journal.entries.firstIndex { $0.key == key }
                let previous = index.map { inner.journal.entries[$0] }
                // Keep the real value from before the first mock, unless something real
                // changed the cookie since the last mock: then that newer value is the real one.
                let keepsBefore = previous.map { $0.layer == .active && $0.written.matches(before) } ?? false
                var entry = CookieEntry(
                    key: key,
                    before: keepsBefore ? previous!.before : before,
                    beforeLaunchID: keepsBefore ? previous!.beforeLaunchID : launchID,
                    written: before.map(CookieWrite.stored) ?? .deleted,
                    launchID: launchID
                )
                if keepsBefore { entry.written = previous!.written }
                Self.put(entry, at: index, in: &inner.journal)
                inner.journal.pending.removeAll { $0.key == key }
                save(inner)
                jar.setCookies([cookie], for: url, mainDocumentURL: mainDocumentURL)
                let after = stored(key)
                if after == before {
                    // The policy refused it, or it changed nothing: no write to undo.
                    if previous == nil { inner.journal.entries.removeAll { $0.key == key } }
                    else if let index { inner.journal.entries[index] = previous! }
                } else {
                    entry.written = after.map(CookieWrite.stored) ?? .deleted
                    entry.launchID = launchID
                    Self.put(entry, at: inner.journal.entries.firstIndex { $0.key == key }, in: &inner.journal)
                    Self.logger.info("Journaled a mocked cookie \(key.name, privacy: .private) for \(key.domain, privacy: .private)")
                }
                save(inner)
            }
        }
    }

    private static func put(_ entry: CookieEntry, at index: Int?, in journal: inout CookieJournal) {
        if let index { journal.entries[index] = entry } else { journal.entries.append(entry) }
    }

    /// Saves unless read-only. Used where a failure must not stop the app's request.
    private func save(_ inner: Inner) {
        guard !inner.readOnly else { return }
        do {
            try store.saveCookieJournal(inner.journal)
        } catch {
            Self.logger.error("Couldn't save the cookie journal: \(error.localizedDescription, privacy: .public)")
        }
    }
}
```

```swift
/// Which entries a discard takes.
public enum CookieScope: String, Sendable, CaseIterable {
    case all
    /// Only entries written in an earlier launch, so an agent can clear what earlier runs
    /// left without touching this launch's pre-attach mocks.
    case earlierLaunches
}

public enum CookieTrigger: String, Sendable {
    case explicit, turnedOff, turnedOn, launch
}

public struct CookieEntryResult: Equatable, Sendable {
    public enum Action: String, Sendable {
        /// The mock created the cookie, and it was deleted.
        case deleted
        /// The real cookie was put back.
        case restored
        /// Something else rewrote the cookie, so it was left.
        case skipped
        /// Something else deleted the cookie, so it was left.
        case gone
        /// A set-aside mocked cookie was put back.
        case reapplied
        /// The entry was dropped without touching storage.
        case dropped
    }

    public var key: CookieKey
    public var action: Action
}

/// What one restore, set-aside or put-back did.
public struct CookieChange: Equatable, Sendable {
    public var trigger: CookieTrigger
    public var date: Date
    public var results: [CookieEntryResult]

    public func count(_ action: CookieEntryResult.Action) -> Int {
        results.filter { $0.action == action }.count
    }
}

/// Storage changed but the journal could not be saved. The journal in memory still
/// matches the file, so the next launch does not undo a cleanup the caller was told of.
public struct CookieSaveFailure: Error, Sendable {
    public var change: CookieChange
    public var error: String
}
```

Add to `CookieKeeper`:

```swift
    /// Whether `record`, read in launch `launch`, could still exist now.
    func isAlive(_ record: CookieRecord, readIn launch: String) -> Bool {
        !record.hasExpired(at: now()) && !(record.isSession && launch != launchID)
    }

    /// Whether the mock's own cookie is gone by its own nature: expired, or a session
    /// cookie of an earlier launch.
    func goneByItself(_ entry: CookieEntry) -> Bool {
        guard case let .stored(record) = entry.written else { return false }
        return !isAlive(record, readIn: entry.launchID)
    }

    /// Puts the real cookie back, or deletes the key when there was none.
    private func putBefore(_ entry: CookieEntry) {
        if let before = entry.before {
            if isAlive(before, readIn: entry.beforeLaunchID), let cookie = before.cookie {
                jar.set(cookie)
            } else {
                jar.delete(entry.key)
            }
        } else {
            jar.delete(entry.key)
        }
    }

    /// The restore table in the spec, for one entry.
    func restore(_ entry: CookieEntry) -> CookieEntryResult.Action {
        let current = stored(entry.key)
        if entry.written.matches(current) {
            putBefore(entry)
            return entry.before == nil ? .deleted : .restored
        }
        if current == nil {
            guard goneByItself(entry) else { return .gone }
            putBefore(entry)
            return .restored
        }
        return .skipped
    }

    /// Runs `body` on the journal and saves it. Storage changes first and the journal is
    /// saved after. If the save fails the journal in memory goes back to what is on disk.
    private func change(
        _ trigger: CookieTrigger,
        _ body: (inout CookieJournal) -> [CookieEntryResult]
    ) throws -> CookieChange {
        try lock.withLock { inner in
            guard !inner.readOnly else {
                throw MapLocalMessage(.cookieJournalUnreadable, ["error": "read-only"])
            }
            var journal = inner.journal
            let change = CookieChange(trigger: trigger, date: now(), results: body(&journal))
            do {
                try store.saveCookieJournal(journal)
            } catch {
                throw CookieSaveFailure(change: change, error: error.localizedDescription)
            }
            inner.journal = journal
            Self.logger.info("""
                Cookies \(trigger.rawValue, privacy: .public): \
                deleted \(change.count(.deleted)), restored \(change.count(.restored)), \
                skipped \(change.count(.skipped)), gone \(change.count(.gone)), \
                reapplied \(change.count(.reapplied)), dropped \(change.count(.dropped))
                """)
            return change
        }
    }

    /// The explicit restore: every active entry in `scope` is restored and every entry in
    /// it is dropped, set aside or not.
    func discard(scope: CookieScope) throws -> CookieChange {
        try change(.explicit) { journal in
            var results: [CookieEntryResult] = []
            var kept: [CookieEntry] = []
            for entry in journal.entries {
                if scope == .earlierLaunches, entry.launchID == launchID {
                    kept.append(entry)
                    continue
                }
                if entry.layer == .setAside {
                    results.append(CookieEntryResult(key: entry.key, action: .dropped))
                    continue
                }
                let action = restore(entry)
                if action == .deleted || action == .restored { journal.pending.append(entry) }
                results.append(CookieEntryResult(key: entry.key, action: action))
            }
            journal.entries = kept
            return results
        }
    }
```

```swift
    private func setAside(_ journal: inout CookieJournal) -> [CookieEntryResult] {
        var results: [CookieEntryResult] = []
        var kept: [CookieEntry] = []
        for var entry in journal.entries {
            guard entry.layer == .active else {
                kept.append(entry)
                continue
            }
            let action = restore(entry)
            results.append(CookieEntryResult(key: entry.key, action: action))
            guard action == .deleted || action == .restored, !goneByItself(entry) else { continue }
            journal.pending.append(entry)
            entry.layer = .setAside
            entry.restoredTo = stored(entry.key)
            kept.append(entry)
        }
        journal.entries = kept
        return results
    }

    private func putBack(_ journal: inout CookieJournal) -> [CookieEntryResult] {
        var results: [CookieEntryResult] = []
        var kept: [CookieEntry] = []
        for var entry in journal.entries {
            guard entry.layer == .setAside else {
                kept.append(entry)
                continue
            }
            let unchanged = stored(entry.key) == entry.restoredTo
            guard unchanged, !goneByItself(entry) else {
                results.append(CookieEntryResult(key: entry.key, action: .dropped))
                continue
            }
            switch entry.written {
            case let .stored(record):
                guard let cookie = record.cookie else {
                    results.append(CookieEntryResult(key: entry.key, action: .dropped))
                    continue
                }
                jar.set(cookie)
            case .deleted:
                jar.delete(entry.key)
            }
            journal.pending.removeAll { $0.key == entry.key }
            entry.layer = .active
            entry.restoredTo = nil
            kept.append(entry)
            results.append(CookieEntryResult(key: entry.key, action: .reapplied))
        }
        journal.entries = kept
        return results
    }

    func setAside(trigger: CookieTrigger) throws -> CookieChange {
        try change(trigger) { setAside(&$0) }
    }

    func putBack(trigger: CookieTrigger) throws -> CookieChange {
        try change(trigger) { putBack(&$0) }
    }

    /// Matches the cookies to the switch: off sets aside, on puts back. Idempotent, so the
    /// engine can call it after any write that may have flipped `enabled`.
    func sync(enabled: Bool, trigger: CookieTrigger) throws -> CookieChange {
        enabled ? try putBack(trigger: trigger) : try setAside(trigger: trigger)
    }

    /// Runs once per launch, before the first request after the plugin is created.
    func reconcileAtLaunch(enabled: Bool) throws -> CookieChange {
        try change(.launch) { journal in
            var results: [CookieEntryResult] = []
            // Restores a kill may have lost, unless the key is in use by a mock again.
            let active = Set(journal.entries.filter { $0.layer == .active }.map(\.key))
            for entry in journal.pending where !active.contains(entry.key) && entry.written.matches(stored(entry.key)) {
                putBefore(entry)
                results.append(CookieEntryResult(key: entry.key, action: .restored))
            }
            journal.pending = []
            // Mock cookies that went away by themselves no longer count.
            journal.entries = journal.entries.filter { entry in
                guard entry.layer == .active, stored(entry.key) == nil, goneByItself(entry) else { return true }
                putBefore(entry)
                results.append(CookieEntryResult(key: entry.key, action: .restored))
                return false
            }
            results += enabled ? putBack(&journal) : setAside(&journal)
            return results
        }
    }
```

```swift
    private func apply(_ change: ConfigurationChange, expectedRevision: Int?) throws -> Configuration {
        let (configuration, flipped) = try lock.withLock { state in
            guard !state.readOnly else { throw ApplyError.readOnly }
            if let expectedRevision, state.configuration.revision != expectedRevision {
                throw ApplyError.conflict(current: state.configuration.revision)
            }
            if case .acknowledgeMockedSession = change {
                store.saveAuthMocked(false)
                state.mayHoldMockedSession = false
            }
            var configuration = try Self.applying(change, to: state.configuration)
            configuration.revision = state.configuration.revision + 1
            configuration.version = Configuration.currentVersion
            try store.save(configuration)
            let flipped = configuration.enabled != state.configuration.enabled
            state.configuration = configuration
            state.issues = configuration.unsupportedIssues
            states.send(state)
            return (configuration, flipped)
        }
        if flipped { syncCookies() }
        return configuration
    }

    /// Moves cookies to match the switch as it is now, not as one write left it, so two
    /// writes racing still end with cookies that match the last state. A failure never
    /// fails the write that caused it.
    private func syncCookies() {
        let enabled = lock.withLock { $0.configuration.enabled }
        let trigger: CookieTrigger = enabled ? .turnedOn : .turnedOff
        do {
            publishCookies(try cookies.sync(enabled: enabled, trigger: trigger))
        } catch let failure as CookieSaveFailure {
            publishCookies(nil, issue: MapLocalMessage(.cookieJournalSaveFailed, ["error": failure.error]))
        } catch {
            publishCookies(nil)
        }

            if let change { state.lastCookieChange = change }
            if let issue { state.issues.append(issue) }
```

```markdown
## Mocked cookies

A `Set-Cookie` in a mocked response goes into `HTTPCookieStorage.shared`, and Map Local
```

- [ ] **Step 3: `docs/design.md`**

Under "## Auth rule and mocked session", add:

```markdown
**Mocked cookies are a layer: off sets them aside, on puts them back.**
`CookieKeeper` journals each key a mock writes, with the real value before it
(`Sources/MapLocalCore/CookieKeeper.swift`).
- The engine performs the write itself, under the journal's lock, so a restore cannot
  fall between a write's read and its store.
- A restore compares the cookie in storage with what the mock left, instead of watching
  real responses. Responses from sessions and hosts Map Local does not intercept never
  reach it, and comparing finds every rewrite.
- Off and on move cookies instead of deleting them, so a switch can be undone by
  switching back (experience.md principle 4), and nothing mocked reaches real requests
  while Map Local is off (principle 10).
- A launch with Map Local off sets cookies aside; a launch with it on keeps them, because
  rules apply with or without Necto.
```
